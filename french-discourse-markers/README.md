# Contextual Classification of French Discourse Markers

**Project type:** Exploratory NLP / introductory machine-learning project  
**Language:** French  
**Status:** Starter implementation — dataset and code require further development and linguistic review.

## Research question

To what extent can a simple machine-learning model identify the discourse functions of French discourse markers from the linguistic context in which they occur?

## Connection to the literature review

The literature review *The Importance of Computational Discourse Analysis* discusses discourse comprehension as inferential processing and describes discourse markers as cues that guide interpretation rather than fixed labels. It also emphasizes annotated discourse resources and the need for linguistically informed computational models.

This project turns one part of that discussion into a small computational investigation: it asks whether surrounding words provide useful evidence for classifying a marker's discourse function.

## Scope and labels

The starter dataset uses three broad labels:

- `consequence`
- `contrast`
- `reformulation`

The examples are manually constructed teaching examples. They are **not** extracted from a published corpus, validated by multiple annotators, or suitable for making general claims about French discourse. The labels are provisional. In particular, `en fait` can have several functions, and the current dataset simplifies those distinctions.


## Files

- `data/discourse_markers.csv`: small illustrative starter dataset.
- `classifier.py`: trains and evaluates simple baselines.
- `notebook.ipynb`: notebook version of the workflow.
- `annotation_guidelines.md`: provisional label definitions and annotation cautions.
- `requirements.txt`: Python dependencies.
- `results/`: output location for reports generated by the script.

## Methods

The script compares:
1. A majority-class baseline.
2. A marker-only model.
3. A context-aware model using the sentence with the target marker replaced by `[MARQUEUR]`.

The context-aware setup is intended to test whether surrounding lexical context helps. This is a small exploratory comparison, not a definitive test of discourse understanding.

The models use TF-IDF features and logistic regression. The dataset is very small, so a single train/test split is unstable. Treat the metrics as a coding demonstration only; do not report them as reliable research findings.

## Run the project

```bash
python -m pip install -r requirements.txt
python classifier.py
```

The script prints precision, recall, F1-score, and a confusion matrix. It also saves a text report in `results/`.

## Limitations and next steps

- The starter examples are constructed, not naturally occurring.
- The three labels are broad and may hide meaningful subtypes.
- The sample is too small for robust generalization.
- TF-IDF does not model long-distance discourse structure or human inference.
- The current project focuses on French; a Persian extension would require language-specific data and annotation decisions.

A responsible next version should use a larger authentic dataset, documented sampling, clearer annotation guidelines, and a more robust evaluation design.
